# Iris Flower Species Identification

A classic multi-class classification project identifying iris species from
petal and sepal measurements, using eight classifiers as a clean baseline.

## Objective
Classify iris flowers into three species from four measurements (petal and
sepal length/width).

## Approach
CRISP-DM workflow: exploratory analysis, train/test split with
cross-validation, and training of 8 classifiers with tuning.

## Results
Most models reached **100% test accuracy** with cross-validation scores
around 93–96%. The Iris dataset is small and well-separated, so high accuracy
is expected — this project serves as a clean baseline demonstrating the full
classification workflow and model-comparison process rather than a difficult
prediction task.

## Models
Logistic Regression, Decision Tree, Random Forest, SVM, KNN, Gradient
Boosting, XGBoost and Naive Bayes.

## Tools
Python, pandas, scikit-learn, XGBoost, matplotlib, seaborn.

## Dataset
Iris dataset (UCI Machine Learning Repository).
